# iiko Service Warden

Небольшая Windows-утилита с графическим интерфейсом для поиска, мониторинга и управления локальными серверами **iiko**.

## Возможности

Программа автоматически находит установленные службы iiko/Tomcat и отображает основную информацию о них:

* имя сервера;
* версию iiko;
* HTTP-порт;
* период хранения данных;
* имя и описание Windows-службы;
* статус службы;
* текущий статус сервера iiko.

Дополнительно через контекстное меню можно:

* открыть папку `Server`;
* запустить конфигуратор Tomcat;
* посмотреть файл лицензий;
* открыть папку с логами;
* посмотреть `startup.log` и `error.log`;
* запустить или остановить Windows-службу.

Кнопка **«Статус iiko»** отправляет запрос к локальному интерфейсу мониторинга iiko и отображает текущее состояние сервера.

## Используемые технологии

* Python
* PySimpleGUI
* psutil
* requests
* ElementTree
* pyperclip

## Требования

Программа предназначена для **Windows** и предполагает наличие установленного локального сервера iiko/Tomcat.

Установка зависимостей:

```bash
pip install PySimpleGUI psutil pyperclip requests
```

## Запуск

```bash
python main.py
```

Для управления Windows-службами может потребоваться запуск программы **от имени администратора**.

## Назначение

Проект создан для упрощения диагностики и администрирования нескольких установленных экземпляров iiko Server без необходимости вручную искать конфигурационные файлы, службы Windows, логи и параметры сервера.
